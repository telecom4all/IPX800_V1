# IPX800 V1 Integration v2.0 pour Home Assistant

🚀 **Version 2.0 - Synchronisation parfaite !**

Intégration robuste pour le module IPX800 V1 de GCE Electronics dans Home Assistant.

## ✨ Nouveautés v2.0

- **Synchronisation parfaite** entre interrupteurs physiques et virtuels
- **Gestion d'état centralisée** avec coordinateur robuste  
- **Communication HTTP** avec vérification d'état automatique
- **Migration automatique** depuis la v1.0
- **Diagnostic avancé** et monitoring

## 🔧 Problèmes résolus

✅ Désynchronisation entre lumières et interrupteurs
✅ États incorrects après commandes
✅ Latence variable  
✅ Race conditions

## 📦 Installation

1. Téléchargez la v2.0
2. Remplacez votre dossier `custom_components/ipx800_v1`
3. Redémarrez Home Assistant
4. Migration automatique !

## ⚙️ Configuration optimisée

- **Intervalle de scrutation** : 0.5-1.0s recommandé
- **Vérification d'état forcée** : Activée par défaut
- **Timeout** : 3-5 secondes
